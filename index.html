استعرض شفرات حية ومحاكاة برمجية حقيقية للغات الأكثر استخداماً في تطوير أدوات الاختراق والحماية.

port_scanner.py 
import socket

def scan_target(ip, port):
    try:
        sock = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
        sock.settimeout(1.0)
        result = sock.connect_ex((ip, port))
        if result == 0:
            print(f"[+] المنفذ {port} مفتوح على الهدف {ip}")
        sock.close()
    except Exception as e:
        print(f"[-] خطأ: {e}")

# تجربة الفحص للهدف المحلي
scan_target("127.0.0.1", 80)

علوم الشبكات النموذجية OSI 7 Layers

7

طبقة التطبيقات (Application Layer)

HTTP, HTTPS, DNS, FTP, SSH
6

طبقة العرض (Presentation Layer)

SSL/TLS, JPEG, ASCII, Encryption
5

طبقة الجلسة (Session Layer)

RPC, NetBIOS, Sockets Session
4

طبقة النقل (Transport Layer)

TCP, UDP, Ports (80, 443, 22)
3

طبقة الشبكة (Network Layer)

IP (IPv4/IPv6), ICMP, Routers
2

طبقة ربط البيانات (Data Link Layer)

MAC Address, Ethernet, Switches
1

الطبقة الفيزيائية (Physical Layer)

Cables, Fiber, Bits (01010)
الطبقة 7: Application Layer Top Layer

تتفاعل هذه الطبقة بشكل مباشر مع البرامج والتطبيقات التي تستخدم الاتصال بالشبكة مثل متصفحات الويب وخوادم البريد. توفر واجهات للبروتوكولات العليا لتداول البيانات.
